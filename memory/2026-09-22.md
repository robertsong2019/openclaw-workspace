### 教训

- edit 工具对 try/catch 结构性改写会孤儿化 catch（语法错误），**结构编辑后必须先 import-check 再跑套件**
- exec preflight 拒绝 `cd X && node …` 形态，用 `node /abs/path.js` 直跑即可
- **tsv 行含反引号时严禁 printf 双引号**——反引号命令替换在 printf 里真执行了（kill/cd 报错），改用 write 工具写临时文件 + cat append
- afm 遗留已知未修（surgical 原则，台账已记）：agentName 拼进 start-<name>.js 脚本路径与内容；modifyAgent 改名只改对象不改注册表键
